# (仮題)アイドルグループ育成ローグライク

弱小芸能事務所「ミツバ企画」の新人プロデューサーとして、オーディションから新しいアイドルグループを立ち上げるブラウザゲームです(試作)。
画面はすべて、会社支給のノートPCのデスクトップという体裁になっています。

## いまできること

- **オーディション(1週間)**
  毎回、手書きの候補者8人から5人と、自動で作った3人が最終候補になります。
  履歴書・宣材写真・審査員メモを読み、空き時間(6コマ)を使って調べてから、選考表で合否を決めます。
  調べ方は、ブラウザでの検索(掲示板・X風SNS「Z」など)、メールでの関係者への問い合わせ、カレンダーでの追加面接の3つです。
- **グループ結成後(ランが終わるまで)**
  最初の1か月は1週間ずつ、そのあとは2週間ずつ進みます。
  仕事の依頼をメールで受けて出演メンバーを選び、カレンダーの空き枠にレッスン・面談・SNS運営・営業を入れて進めます。
  メンバーごとの事件、ランダムな事件、シングルの発売、卒業の申し出、追加オーディション、メンバーとの交際などが起きます。
- **ランの終わり方**
  解散(自分で決める/人数が足りない)、事務所の倒産(借金が1,000万円を超える)、全員の卒業、炎上による活動休止、交際の発覚による解任。
  終わると百科事典風の記事と「世間の評価」のランクが出て、デスクトップの「過去の担当グループ」に残ります。ほかに次のランへ引き継ぐものはありません。

最初からやり直すときは、スタートメニューの電源ボタンを押してください。

## Render で公開して遊ぶ

HTML・CSS・JavaScript だけでできているので、Render の **静的サイト(Static Site)** として無料で公開できます。設定は `render.yaml` に書いてあります。

1. https://dashboard.render.com を開いてログインする
2. 右上の **New +** → **Blueprint** を選ぶ
3. リポジトリの一覧から **thinline0924-cell/idol-roguelike** を選ぶ(出てこないときは「Configure account」で GitHub の許可にこのリポジトリを追加)
4. **Apply**(または Deploy Blueprint)を押す
5. 1〜2分で公開が終わる。表示された `https://idol-roguelike-xxxx.onrender.com` のような URL を開くと遊べる

`main` に変更が入ると、Render が自動で公開し直します。

## 手元で遊ぶ

このフォルダで次のコマンドを実行して、`http://localhost:8000/` を開いてください。

```
python3 -m http.server
```

## ファイル

- `index.html` / `style.css` … 画面
- `js/os.js` … ウィンドウ・タスクバー・通知など「PCとしての動き」
- `js/icons.js` … アイコン
- `js/data.js` … 手書きの候補者8人のデータ(資料・検索結果・問い合わせの返事など)
- `js/gen.js` … 候補者の自動生成(名前・出身・経歴のタイプ・裏の事情)
- `js/texts.js` … 文章の素材集(依頼文・現場報告・Zの投稿・面談・交際など)
- `js/events.js` … ランダムな事件と、裏の事情から起きる事件
- `js/game.js` … オーディションの週と各アプリ
- `js/group.js` … グループ結成後(ターンの進行・仕事・卒業・交際・終わり方・評価)
